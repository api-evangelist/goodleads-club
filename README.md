GoodLeads provides formation‑grade B2B intelligence, delivering newly formed U.S. business owner contact data—including name, mailing address, and verified phone or email where available. The platform enables developers to integrate lead acquisition via a simple API, offering real‑time counts, pricing, and compliance information. Users can browse, purchase, and receive data through a secure checkout, supporting outbound sales, nurturing, and market analysis workflows.

**Areas:** Company · B2B · Lead-Data · API · Sales-Enablement

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for GoodLeads: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
